## Why
El usuario quiere subir el juego a su cuenta de GitHub y usarlo online.

## What Changes
- Crear un repositorio en la cuenta indicada y subir el proyecto.
- Configurar GitHub Pages desde la raíz de main.
- Comprobar la URL HTTPS y actualizar la documentación con el enlace real.

## Impact
- Afecta a la entrega y publicación de juego.
- Mantiene la aplicación estática y sin servicios externos durante las partidas.
